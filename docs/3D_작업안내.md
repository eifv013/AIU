# SD 3D 캐릭터 만들기: 처음부터 게임에 들어가기까지

램파트 한 명으로 먼저 끝까지 해 보고, 잘 되면 나머지 네 명을 같은 순서로 진행해요.

## 전체 흐름과 맡는 사람
| 단계 | 어디서 | 누가 | 나오는 것 |
|---|---|---|---|
| 1. SD 그림 | 쓰시던 그림 생성기 | Guar | 정면, 뒤, (옆), 방패 그림 |
| 2. 3D 모델 | Tripo (tripo3d.ai) | 로그인은 Guar, 나머지는 Claude도 가능 | knight.fbx |
| 3. 뼈대와 동작 | Mixamo (mixamo.com) | 로그인은 Guar, 나머지는 Claude도 가능 | 동작별 fbx 파일 |
| 4. 손질 | 컴퓨터의 블렌더 | Claude (데스크톱 앱 연결) | knight.glb 한 파일 |
| 5. 게임 적용 | AIU 코드 | Claude | 전투 화면에서 움직이는 램파트 |

## 1. SD 그림 받기 (그림주문서_3_SD.md)
1. 새 대화를 열고 예전 램파트 B 전신 그림(회색 배경)을 붙인 뒤, 주문서의 **공통 정면 칸**에 램파트 [OUTFIT NOTE]를 넣어 보내요.
2. 같은 대화에서 **공통 뒤 칸**을 보내요. 붙일 그림은 방금 받은 SD 정면 그림이에요.
3. 같은 대화에서 **공통 옆 칸**도 보내요. 옆 그림은 따로 그리면 모양이 어긋나기 쉬워서, 3D가 오히려 일그러질 수 있어요. 받긴 하되, 2단계에서는 정면과 뒤만 먼저 써 보고 결과가 아쉬울 때 옆을 더해요.
4. 새 대화에서 램파트 B 그림을 붙이고 **무기 칸**(방패)을 보내요.
5. 받은 그림에서 확인할 것:
   - 팔이 몸에서 떨어져 있는지
   - 손이 비어 있는지
   - 정면과 뒤의 키, 머리 크기가 같은지
   - 배경이 회색 단색인지
   - 걸리면 주문서의 "말을 안 들을 때" 문장으로 다시 그려요.

## 2. Tripo에서 3D 모델 만들기
1. tripo3d.ai에 들어가 구글 계정으로 가입하고 로그인해요. 무료 크레딧으로 시험할 수 있어요.
2. 이미지로 3D 만들기 메뉴에서 **여러 장(Multi-view)** 방식을 골라요. Tripo는 정면, 왼쪽, 뒤, 오른쪽 네 방향까지 받아요.
3. Front 칸에 SD 정면, Back 칸에 SD 뒤 그림을 넣어요. 옆은 비워 둬요.
4. 설정
   - 텍스처(색 입히기)는 켜요.
   - 면 수 제한(Face limit)이 있으면 2만 이하로 해요. 휴대폰에서 다섯 명이 같이 돌아가야 해서요.
   - 로우폴리(Smart Low Poly) 같은 게임용 옵션이 있으면 켜요.
5. 만들기를 누르고, 결과를 돌려 보며 확인해요.
   - 얼굴이 깨지지 않았는지
   - 팔과 몸통이 붙지 않았는지
   - 뒤통수와 등이 멀쩡한지
   - 이상하면 다시 만들기를 누르거나, 옆 그림을 더해서 다시 만들어요.
6. 내보내기(Export)에서 **FBX**로 받아요. 파일 이름은 `knight.fbx`로 해요.
   - Tripo에도 자동 뼈대 기능이 있지만, 동작이 많은 Mixamo로 가요.
   - 그래서 Tripo에서는 뼈대 없이 모델만 받아요.

## 3. Mixamo에서 뼈대와 동작 붙이기
1. mixamo.com에 들어가 Adobe 계정으로 로그인해요. 없으면 무료로 만들면 돼요. Mixamo 동작은 상업 게임에 써도 돼요.
2. 오른쪽 **Upload Character**를 눌러 `knight.fbx`를 올려요.
   - 색이 안 보이면 2단계에서 FBX를 내보낼 때 텍스처를 파일 안에 넣는 옵션(embed media)을 켜고 다시 받아요.
3. 캐릭터가 정면을 보고 서 있으면 Next를 눌러요. 누워 있거나 뒤를 보면 화면의 회전 버튼으로 바로 세워요.
4. 동그라미 표시(마커) 다섯 종류를 끌어다 놓아요.
   - 턱: 턱 끝
   - 손목 둘
   - 팔꿈치 둘
   - 무릎 둘
   - 사타구니: 다리가 갈라지는 곳
   - SD라 목이 짧으니 턱은 머리와 몸이 만나는 곳보다 살짝 위에 둬요.
5. Skeleton LOD는 손가락 없는 것(No Fingers)을 골라요. SD 손은 단순해서 손가락 뼈가 오히려 엉켜요. Next를 눌러요.
6. 자동으로 뼈대가 들어가면 캐릭터가 움직이는 미리보기가 나와요. 팔이나 다리가 찢어지면 Back으로 가서 마커를 다시 놓아요. 괜찮으면 Next를 눌러요.
7. 왼쪽 검색창에서 동작을 찾아 하나씩 받아요.

   | 받을 파일 | 검색어 | 설정 |
   |---|---|---|
   | knight_idle | idle | 그대로 |
   | knight_walk | walking | In Place 체크 (제자리 걷기) |
   | knight_attack | punch 또는 shield (방패 밀치기 느낌) | 그대로 |
   | knight_hit | hit reaction | 그대로 |
   | knight_die | dying | 그대로 |

8. 다운로드 설정
   - Format: FBX Binary
   - Skin: 첫 번째 파일(knight_idle)만 **With Skin**, 나머지는 **Without Skin**. 동작 파일에는 몸이 필요 없어서 용량이 줄어요.
   - Frames per Second: 30
   - Keyframe Reduction: none
9. 받은 파일 다섯 개와 방패 그림을 한 폴더에 모아요. 예: 문서/AIU_3D/knight

## 4. 블렌더 손질 (제가 해요)
- 데스크톱 앱으로 이 대화를 열고 그 폴더를 연결해 주시면, 제가 컴퓨터의 블렌더를 직접 써요.
- 하는 일
  - 동작 다섯 개를 한 캐릭터에 합쳐요.
  - 방패를 3D로 만들어 오른손 뼈에 붙여요. 방패 그림은 2단계와 같은 방법으로 3D로 만들어요.
  - 툰 느낌으로 색을 정리해요.
  - 텍스처를 줄여요.
  - `knight.glb` 한 파일로 내보내요.
- 블렌더가 없으면 blender.org에서 무료로 설치하면 돼요.

## 5. 게임 적용 (제가 해요)
- 전투 화면의 요원만 3D로 바꾸고, 이상체와 근원체는 지금 그림을 그대로 둬요.
  - 서 있기, 걷기, 공격, 맞기, 쓰러짐이 상황에 맞게 부드럽게 이어져요.
  - 이미 넣은 히트스톱, 화면 흔들림, 이펙트도 그대로 써요.
- 휴대폰 두 크기에서 프레임과 용량을 확인해요. 램파트가 괜찮으면 나머지 네 명을 같은 순서로 진행해요.

## 로그인만 해 주시면
Tripo와 Mixamo는 컴퓨터의 브라우저에서 로그인만 해 두시면, 2단계와 3단계를 제가 브라우저로 진행할 수 있어요. 파일 올리기, 마커 놓기, 동작 받기까지 할 수 있어요. 비밀번호는 제가 입력하지 않아요.
