# 결제, 광고 연결 방법

게임 안 화면(상점, 패스, 보석 충전, 광고 보상)은 다 만들어져 있어요.
현재는 **시험 모드**라 결제는 실제 돈이 나가지 않고, 광고는 3초짜리 시험 화면이 나와요.
실제로 연결할 곳은 `src/game.html` 의 두 군데뿐이에요.

## 1. 결제 (`Pay.buy`)
- 구글 플레이 콘솔 → 인앱 상품에 아래 ID 로 상품을 만들어요. (게임 안 `PRODUCTS` 와 같아야 해요)

| 게임 안 | 상품 ID | 가격 |
|---|---|---|
| 신입 수사관 환영 패키지 | aiu_pack_new | 1,100원 |
| 호출 레벨 지원 패키지 | aiu_pack_summon | 9,900원 |
| 월정액 보급 | aiu_monthly | 5,500원 |
| 광고 제거 | aiu_no_ads | 7,500원 |
| 수사 패스 | aiu_pass_s1 | 9,900원 |
| 보석 60 ~ 6,000 | aiu_gem_60 ~ aiu_gem_6000 | 1,200원 ~ 99,000원 |

- 플러그인 설치 (예: `cordova-plugin-purchase` 또는 `@capgo/capacitor-purchases`)
- `Pay.test = false` 로 바꾸고, `Pay.buy(key, price, name)` 안에서 `PRODUCTS[key]` 상품을 결제하게 바꿔요.
  결제가 끝나면 `true`, 취소나 실패면 `false` 를 돌려주면 돼요. 보상 지급은 이미 되어 있어요.

## 2. 광고 (`Ads.show`)
- AdMob 에서 앱을 만들고 보상형 광고 단위를 만들어요. 자리 이름은 `AD_UNITS` (ad_gold_buff, ad_shop_reward, ad_mail).
- 플러그인 설치: `@capacitor-community/admob`
- `Ads.test = false` 로 바꾸고, `Ads.show(unit)` 안에서 보상형 광고를 띄워요. 끝까지 보면 `true`.
- 광고 제거(aiu_no_ads)를 산 사람은 광고 없이 바로 보상을 받아요 (이미 되어 있음).

## 3. 출시 전 확인
- 결제 영수증 확인(서버 검증)은 출시 전에 따로 붙여야 해요.
- 개인정보처리방침에 광고 ID 사용 문구를 넣어요.
