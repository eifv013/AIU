# 그림 주문서 4: 앱 아이콘과 시작 그림

APK는 깃허브에 올릴 때마다 자동으로 만들어져요(`.github/workflows/apk.yml`).
아이콘과 시작 그림은 아래 파일을 **같은 이름, 같은 크기로 바꿔 넣고 올리기만 하면** 다음 APK에 들어가요.
지금 들어 있는 것은 AIU 로고로 만든 임시 그림이에요(`node tools/make_app_icons.js` 로 다시 만들 수 있음).

| 파일 | 크기 | 바탕 | 쓰이는 곳 |
|---|---|---|---|
| `assets/icon-only.png` | 1024×1024 | 꽉 채움 | 옛 안드로이드 아이콘, 스토어 아이콘 |
| `assets/icon-foreground.png` | 1024×1024 | **투명** | 요즘 안드로이드 아이콘의 앞 그림 |
| `assets/icon-background.png` | 1024×1024 | 꽉 채움 | 요즘 안드로이드 아이콘의 뒤 그림 |
| `assets/splash.png` | 2732×2732 | 꽉 채움 | 앱이 켜질 때 잠깐 보이는 그림 |
| `assets/splash-dark.png` | 2732×2732 | 꽉 채움 | 위와 같음(어두운 모드) |

## 꼭 지킬 것
- **안전 영역**: 요즘 안드로이드는 아이콘을 동그라미, 둥근 네모 등으로 잘라요. 앞 그림의 중요한 부분(얼굴, 글자)은 **가운데 지름 660px 원 안**에 넣어요. 바깥 180px 테두리는 잘려도 되는 자리예요.
- 앞 그림은 바탕을 **투명**으로(PNG). 뒤 그림은 무늬나 색만.
- 시작 그림은 정사각인데 휴대폰마다 위아래, 양옆이 잘려요. 로고와 글자는 **가운데 1200×1200 안**에만.
- 아이콘에는 작은 글자를 넣지 않아요(휴대폰에서 48px로 줄어들면 안 보임). 글자는 AIU 세 글자까지만.

## 실제 게임 참고
- 세븐나이츠 키우기, 쿠키런 같은 키우기 게임 아이콘은 **대표 캐릭터 얼굴을 크게** 넣고 배경은 단색이나 빛 번짐으로 단순하게 해요. 글자 로고는 작게 붙이거나 아예 없어요.
- 그래서 AIU도 **나이트폴(대표 전설 요원) SD 얼굴 + 뒤에 보랏빛 균열** 구성을 추천해요.

**뒤 그림 (icon-background.png)**

**시작 그림 (splash.png)**
> 지금처럼 로고만 두거나, 위 뒤 그림을 2732×2732로 키워서 가운데에 AIU 로고를 얹어요.

## 바꾸는 순서
1. 위 문구로 그림을 만들어요(앞 그림은 투명 바탕으로 저장).
2. 파일 이름을 표에 맞게 바꿔요.
3. 대화창에 올려 주시면 제가 크기와 안전 영역을 맞춰 `assets/` 에 넣고 올려요.
4. 몇 분 뒤 깃허브 Releases 의 "AIU 최신 APK"에서 새 APK를 받아요.
